Специфікація Grid — це сорок з гаком властивостей. Я вивчив три
й досі не зустрів завдання, де їх не вистачило.

## Перша: grid-template-columns

Вона одна відповідає на питання «скільки колонок і якої ширини».

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
}
```

Цей рядок робить адаптивну сітку **без жодного медіазапиту**. Браузер сам
рахує, скільки колонок по 280px влізе, а `1fr` розтягує їх на решту місця.

## Друга: gap

Проміжки між клітинками. Раніше для цього ставили `margin` кожному
елементу й потім прибирали його в останнього — Grid прибрав цю мороку.

## Третя: grid-column

Коли одна картка має займати дві колонки:

```css
.card--wide {
  grid-column: span 2;
}
```

## А решта?

Решта — для складних випадків: іменовані області, вирівнювання окремих
клітинок, підсітки. Вони знадобляться, коли знадобляться. Учити їх
наперед — те саме, що вивчити всі дорожні знаки перед першим уроком водіння.
